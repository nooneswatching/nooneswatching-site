# NO/ONES/WATCHING

Joshua Newton's portfolio, version 3: an endless, pannable canvas of every piece of
work, with filters, an Index view, an Info page and a lightbox for single pieces and
multi-asset projects. Designed in Figma (`Portfolio v3 · Designs`), built as plain
HTML/CSS/JS generated by one Node script. No framework, no npm dependencies
(Lenis is vendored for the scrolling views).

```
src/work.mjs             every piece and project (the only file to edit to add work)
src/content.mjs          site meta, socials, Info page copy
src/media-manifest.json  pixel sizes of every media file (generated by scripts/media.mjs)
build.mjs                renders ./dist from the data
static/styles.css        design tokens (dark + light), every component, phone layout
static/main.js           canvas, filters, view switch, lightbox, Index, routing
static/vendor/lenis.min.js  smooth scrolling for Index and Info
static/assets/img, video    originals (lightbox)
static/assets/thumb         640px thumbnails (canvas, filmstrips, Index), generated
static/assets/poster        video posters, generated
static/assets/fonts         PP Neue Montreal 400 (everything) and 500 (logo wordmark)
scripts/media.mjs        generates thumb/, poster/ and the manifest with ffmpeg
scripts/serve.mjs        zero-dependency local server with the same routing as Vercel
vercel.json              build, clean URLs, deep-link rewrite, redirects from the old site
```

## Run it

```
npm run dev      # build, then serve dist/ at http://localhost:3000 (rebuild after edits)
npm run build    # build only (what Vercel runs)
npm run media    # after adding files to static/assets/{img,video}: thumbs, posters, sizes
```

`npm run media` needs `ffmpeg` and `ffprobe` on the PATH. Its outputs are committed, so
the Vercel build never needs ffmpeg.

## URLs

| URL | What |
| --- | --- |
| `/` | Grid (the canvas). `?f=brand` etc. preselects a filter |
| `/list` | Index view (`/index` would collide with `index.html`, so it is `/list`) |
| `/info` | Info |
| `/work/<project-slug>` | Lightbox on the project's first asset |
| `/work/<project-slug>/<n>` | Lightbox on asset n of the project (rewritten to the project page) |
| `/work/<piece-slug>` | Lightbox on a single piece |

The old Framer-era URLs (`/Projects`, `/projects/frame-v4`, ...) redirect to the new
ones in `vercel.json` and `scripts/serve.mjs`.

## Adding work

Everything is in `src/work.mjs`.

- A **project** is an object in `projects` with copy (`title`, `client`, `year`, `role`,
  `agency`, `disciplines`, `description`) and an ordered `assets` list of
  `[media, title, caption]`. `cover` is the id of one of its assets.
- A **single piece** is an entry in `singles`: `[media, title, caption, { client, year,
  disciplines, projectId? }]`. `projectId` only adds the "From <project> ↗" link.
- `media` is `img(id, ext)`, `vid(id)` or `todo(id, label)` for a file you still have
  to supply (renders as a labelled placeholder tile). Files live in
  `static/assets/img/<id>.<ext>` and `static/assets/video/<id>.mp4`.
- `bg` on a media item is a backing colour for PNGs with transparency, nothing else.
- Disciplines are `brand`, `product`, `campaign`, `motion`, `web`.

Then `npm run media` (if you added files) and `npm run build`. Counts, filters, the
Index and every URL are derived from the data.

## Deploying

Production (`nooneswatching.me`) is the `main` branch. v3 work goes to a long-lived
dev branch that the project's `*.vercel.app` domain is assigned to (Vercel: Project →
Settings → Domains → assign the domain to a Git branch). Nothing merges to `main`
without Josh's go-ahead.

## Notes

- Theme follows `prefers-color-scheme`. There is no toggle by design.
- Fonts: PP Neue Montreal, self-hosted. Check the Pangram Pangram license covers
  web self-hosting.
- Google Analytics id lives in `site.gaId` in `src/content.mjs`.
- `REPEAT_SMALL_SETS` at the top of `static/main.js` toggles whether a small filtered
  set keeps tiling infinitely or shows as a finite, centred canvas.
